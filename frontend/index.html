Speculative Decoding Playground

Draft model: Qwen2.5-0.5B-Instruct  →  Target model: Qwen2.5-1.5B-Instruct

How this works

Normally, a language model produces exactly one token per forward pass through the (expensive) target model. Speculative decoding speeds this up by having a small, cheap draft model guess the next K tokens first. The target model then checks all K guesses in a single forward pass instead of one-at-a-time.

  • Every guessed token that matches what the target would have picked itself is accepted for free.
  • The first guess that doesn't match is rejected, and everything after it in that round is discarded.
  • The target always contributes one bonus token of its own at the end of the round — either continuing past a full acceptance, or replacing the first rejected guess.

The output is identical to running the target model alone (both use greedy decoding here) — speculative decoding changes how many expensive target passes it takes to get there, not what gets generated.
